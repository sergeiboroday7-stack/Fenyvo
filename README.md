# FENYVO

**FENYVO — мессенджер для Android и Windows с приватной перепиской, звонками, обменом файлами и защищённым пространством ENIGMA.**

FENYVO находится в активной разработке. В приложении есть личные и групповые чаты, голосовые сообщения, медиа, аудио- и видеозвонки, а также сценарии переноса аккаунта между устройствами. Отдельная функция **FENYVO ENIGMA** предназначена для временного общения по приглашению.

**Актуальная публичная версия:** `1.8.2`, **Android build 16329 · Windows build 16329** (26 ноября 2026 года).

**Официальный сайт:** [fenyvo.com](https://fenyvo.com)

**Исходный код версии 16329:** ветка [`release/fenyvo-1.8.2-16329-enigma`](https://github.com/sergeiboroday7-stack/Fenyvo/tree/release/fenyvo-1.8.2-16329-enigma), коммит [`eb6952a`](https://github.com/sergeiboroday7-stack/Fenyvo/commit/eb6952a082c3bc74a7d96c138f94e07b212596d7).

> **Статус:** тестовый релиз. Публикация исходного кода и прохождение автоматических тестов не означают, что каждый сценарий подтверждён на реальных устройствах или прошёл независимый аудит безопасности.

## Основные возможности

- Личные и групповые переписки; текст, фотографии, видео, файлы и голосовые сообщения.
- Реакции, закреплённые сообщения и локальные сведения о вызовах.
- Личные аудио- и видеозвонки; групповые видеозвонки с участниками сцены и зрителями.
- Управление микрофоном, камерой и устройством звука; на Android — громкая связь, на Windows — системное аудиоустройство и гарнитура.
- Android push-уведомления через Firebase; уведомления и системный трей Windows.
- Локальное хранение данных, восстановление связи после кратковременного обрыва.
- QR-сценарий переноса аккаунта на другое устройство и восстановление связей с контактами.
- Отдельное пространство **ENIGMA** для временного защищённого общения по приглашению.

Это обзор возможностей проекта, а не гарантия, что каждый вариант поведения уже проверен на текущей платформе и устройстве. Детали поддерживаемых сценариев уточняются тестами.

## FENYVO ENIGMA

**ENIGMA — выделенное в интерфейсе пространство для временных и скрытых чатов.** Приглашения открываются по ссылке вида `https://fenyvo.com/t/<token>`. Токен приглашения не следует размещать в публичных отчётах, логах или репозиториях.

**Что реализовано в исходниках сборки 16329:**

- Формирование и обработка ссылок-приглашений, отдельный экран временного общения.
- Запрос присоединения с подтверждением владельцем; проверки контекста аккаунта и сокета.
- Отдельный временный E2EE-контекст на основе компонентов Signal-подобного протокола.
- Завершение чата у обоих участников; завершение сеанса само по себе не удаляет отображённую историю сообщений.
- Ограничения на повторное использование решений о присоединении, проверку срока действия и некорректных приглашений.
- Страница приглашения на сайте `/t/...`, опубликованная для перехода к приложению.

**В разработке и на дополнительном тестировании:** раскрытие профиля по запросу, увеличение аватарки после согласия, взаимно подтверждаемый переход из ENIGMA в обычный чат для медиа и звонков, проверка приглашений в реальном мобильном браузере и восстановление временных сессий в различных сетевых условиях.

ENIGMA **не следует интерпретировать как гарантию полной анонимности**: фактические свойства конфиденциальности зависят от реализации, устройств, метаданных и проверенного протокола.

## Безопасность и перенос аккаунта

Личная переписка FENYVO проектируется с обязательным сквозным шифрованием (E2EE). Безопасность конкретного обмена зависит от корректной работы ключей, проверки идентичности и устройства собеседника. Не все типы коммуникаций имеют одинаковые подтверждённые свойства защиты; **аудио- и видеозвонки не заявляются как E2EE в этой версии**.

При смене телефона предусмотрен QR-перенос аккаунта с подтверждением на старом устройстве. Пользователь ранее подтвердил успешный перенос на тестовой сборке 6308 и работу QR-переноса в последующих сборках. Полная сохранность всех контактов, переписок и E2EE-сессий при любых обрывах или повторных переносах требует отдельных проверок.

### Восстановление доступа

В проекте предусмотрено привязывание 12 секретных слов для восстановления доступа. Сервер хранит проверочные сведения, а не сами слова. Сценарий смены пароля использует одноразовый подписанный запрос с ограничениями по аккаунту и IP. Серверная функция включается только при явной настройке `FENYVO_RECOVERY_ENABLED=true`. Не считайте её доступной на конкретном сервере без проверки настроек развёртывания и полного теста на устройстве.

### Защита исходного кода

В Git **не должны попадать** `.env`, ключи и пароли, Firebase Admin credentials, Android signing keystore, `android/key.properties`, секреты TURN, пользовательские базы, медиа, FCM-токены, диагностические дампы и build-кеши.

Android release подписывается постоянным ключом FENYVO; приватный ключ и пароль не публикуются. При изменении криптографии, передачи ключей, управления устройствами или сессий E2EE требуется отдельная проверка безопасности.

## Звонки и групповые сцены

FENYVO поддерживает личные аудио- и видеозвонки с использованием WebRTC. На Android доступно переключение громкой связи, на Windows используется системная гарнитура и аудиоустройство. Приложение отображает состояния вызовов, слабого соединения и восстановления после краткого обрыва.

Групповые видеозвонки предусматривают роли владельца, ведущего, модератора, участников сцены и зрителей; зритель может отправить запрос на выход на сцену. По ранее документированному сценарию поддерживается до четырёх участников аудио/видеосцены. Доступность отдельных ролей и сценариев необходимо проверять на целевых сборках.

В сетях, где прямое соединение через STUN невозможно, может потребоваться TURN. TURN-учётные данные нельзя размещать в открытом репозитории.

## Приложение и публичный сайт

Приложение написано на **Flutter / Dart**. Серверная часть использует **Node.js**; внешний HTTPS/WSS принимает nginx. Публичный WebSocket-адрес приложения:

```text
wss://fenyvo.com/ws
```

Исходники сайта находятся в `website/`. Сайт локализован на русский, украинский и английский языки, публикует файлы загрузок и SHA-256, метаданные версий и счётчики начатых скачиваний.

Ссылки `/u/...` служат для контактов, а `/t/...` — для приглашений ENIGMA. Публикация HTML и проверка ответа сервера не заменяют проверку открытия приложения в настоящем браузере Android.

## Разработчикам

### Сервер

```bash
npm ci
node server.js
```

Настройки задаются переменными окружения или локальным `.env` по шаблону `.env.example`. В рабочем развёртывании Node.js размещается за nginx; приложение сервера не должно бесконтрольно открываться напрямую в интернет. Исторически локальный порт серверной службы используется через `127.0.0.1:8080`; проверьте настройки конкретного размещения.

### Android

```bash
flutter pub get
flutter build apk --release --target-platform android-arm64 --dart-define=FENYVO_SERVER_URL=wss://fenyvo.com/ws
```

Для точного воспроизведения релиза также требуются соответствующие настройки номера сборки, Android SDK и release signing. Одной команды выше недостаточно для гарантии побайтового совпадения с опубликованным APK. Старое имя `SPARTAN_SERVER_URL` может присутствовать как резерв для совместимости старых локальных сценариев.

### Windows

```bash
flutter pub get
flutter build windows --release
```

Результат собирается в Windows release-каталоге. Для распространения приложения требуется полный комплект файлов и установщик; один `fenyvo.exe` не является готовым дистрибутивом.
