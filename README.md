# SPARTAN CHAT — SPARTAN OUTBOX 1.0 / 4116

Актуальный снимок исходников Android/Windows-мессенджера и Node.js-сервера
от **09.09.2026**. Продолжает проверенную версию GROUP VOICE V1 / BLUE GOLD FIX2.
Это проверенная владельцем тестовая версия, а не заявление о готовности
всех функций для любых устройств и сетей.

Windows Release также проверен на Visual Studio 18 после настройки единого
динамического MSVC runtime для Firebase/Flutter. Бинарные файлы и локальные
данные в репозиторий не включаются.

## Что есть в этой версии

- Собственный сине-золотой интерфейс COMMAND DECK с адаптивной компоновкой для
  Android и Windows, статусами контактов и центральной кнопкой PULSE.
- SIGNAL STREAM в чате: карточки сообщений со срезанными углами, линия событий,
  статусная золотая грань и плавающая строка ввода.
- Windows-клиент работает в системном трее, показывает локальные уведомления
  при скрытом окне и восстанавливается повторным нажатием ярлыка без запуска
  лишних копий процесса.
- После временной потери сервера клиент автоматически переподключается и
  синхронизирует офлайн-сообщения, контакты, группы, звонки и PULSE.
- Личные текстовые сообщения сохраняются в локальной исходящей очереди,
  отображаются сразу и автоматически отправляются после восстановления связи.
- Статусы ожидания, отправки, доставки и прочтения видны непосредственно в
  карточке сообщения; повторная отправка сохраняет исходный ID.
- COMMAND DECK показывает текущее состояние соединения с сервером.
- Поиск контактов, фильтры личных/групповых чатов и сохранённые сообщения.
- Текст, фото, видео, файлы, голосовые сообщения, реакции и закрепы.
- Смайлики в строке ввода, отправка/пересылка медиа.
- Личные аудио- и видеозвонки, таймер, история и управление микрофоном.
- Переключение громкой связи на телефоне, экран входящего звонка с аватаром.
- Групповые **голосовые** звонки до четырёх участников.
- Приглашение, присоединение, выход и повторный вход в групповой звонок.
- Выход создателя не завершает разговор остальных участников.
- SPARTAN PULSE: предложение созвониться в выбранное временное окно и
  автоматический запуск звонка после подтверждения готовности обоих участников.
- SPARTAN SHIELD: локальное предупреждение о подозрительных входящих сообщениях
  с признаками запроса кода, денег или доступа; новое сообщение проверяется снова.
- SPARTAN TRUST 1.0: локальная отметка доверия, блокировка и жалоба на контакт.
- SPARTAN TRUST 1.1: блокировка скрывает новые входящие сообщения; жалоба
  требует причины и подтверждается в приложении.
- Экран завершённого личного звонка закрывается сразу; очистка WebRTC-ресурсов
  ограничена тайм-аутами и больше не удерживает интерфейс звонка.
- Серверный AI-автоответчик; ключ задаётся на сервере и не входит в исходники.

## Известные ограничения

- Группового видео пока нет.
- Для группового звонка приложение должно оставаться открытым.
  Пробуждение закрытого приложения групповым вызовом не реализовано.
- Групповой звук передаётся напрямую между устройствами (mesh), максимум 4 участника.
- Настроен STUN, но не TURN: звонки через разные сети и сложный NAT не гарантированы.
- После разрыва сети требуется повторное присоединение.
- Нет отдельной истории групповых вызовов и подсветки говорящего.
- Известная проблема чёрного видео с телефона на Windows отложена;
  исправленной в этой версии она не считается.
- Возможны лаги; универсальная стабильность и производственная безопасность
  этой публикацией не подтверждаются.
- Исходящая очередь пока охватывает только личный текст: медиа, голосовые и
  групповые сообщения без активного соединения не ставятся в очередь.

## Состав проекта

- `lib/` — Flutter-приложение.
- `android/`, `windows/` — платформенный код.
- `assets/` — штатные логотипы, оформление и звуки.
- `server.js` — сервер сообщений/медиа и интеграция функций.
- `call_signaling.js`, `group_call_signaling.js` — сигнализация звонков.
- `test/` — Flutter- и Node-тесты, экранные эталоны.
- `tools/generate_ringtone.py` — генератор фирменного звонка.
- `pubspec.lock`, `package-lock.json` — зафиксированные зависимости.

Личные базы, медиа пользователей, аватарки, FCM-токены, секретные ключи,
SDK, кеши, временные файлы и APK в Git не входят. Локальные сценарии запуска,
привязанные к папке действующего сервера, также не переносятся.
Обновление исходников на GitHub не перезапускает сервер и не устанавливает
новую сборку на устройства.

## Среда и проверки разработчика

Проверенная локальная среда: Flutter 3.47.2, Dart 3.13.2, Node.js 24.19.0,
Java 17. Android: compile/target SDK 36, min SDK 24, NDK 28.2.13676358,
Gradle 9.1.0, Android Gradle Plugin 9.0.1.

```powershell
flutter pub get
flutter analyze lib test
flutter test
node --test test/call_signaling.test.cjs test/group_call_signaling.test.cjs
```

Для запуска сервера нужны его зависимости (`npm ci`) и собственная локальная
конфигурация Firebase Admin; входная точка — `node server.js`.
Адрес сервера задаётся на экране входа приложения. Используются порты 8080 и 8081.
Не запускайте вторую копию сервера поверх уже занятого порта.

Конфигурация Android сохранена как в рабочем проекте: она ожидает локальный NDK
в `.ndk_local_28.2.13676358/`. SDK и ключ подписи в Git отсутствуют.
Перед сборкой на другом компьютере нужно настроить локальные пути SDK/NDK.
Текущая тестовая Android-сборка использует прежний локальный debug-ключ;
для обновления установленных приложений нужен тот же ключ, его нельзя
публиковать. Текущие исходники имеют versionName `1.5.0` и versionCode `4115`.
Последняя отдельно проверенная универсальная APK-сборка остаётся версией
`1.4.1+4114` и включает ARM32 и ARM64; Android 4115 ещё не объявляется
проверенным. Перенос исходников не публикует готовый APK.

Windows требует установленного C++-компилятора и инструментов сборки Flutter.
Локальный NuGet CLI может находиться в `%LOCALAPPDATA%/NuGet/nuget.exe`; если
он установлен, CMake использует его без повторной загрузки. Предупреждение
MSVC LNK4078 для известной секции `.voltbl` предсобранных библиотек подавлено,
при этом все цели продолжают использовать единый динамический MSVC runtime.
Публикация исходников не является готовым установщиком Windows.
Готовые сборки пока распространяются владельцем отдельно, не в исходниках.
