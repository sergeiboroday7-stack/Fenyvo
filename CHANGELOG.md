# Журнал изменений SPARTAN CHAT

## 2026-10-01 — LEGAL ACCEPTANCE / LOCAL CANDIDATE 1.8.0+4225

- Подготовлены страницы Политики конфиденциальности, Условий использования,
  допустимого использования и поддержки с фактическим описанием данных Fenyvo.
- Перед загрузкой APK добавлено окно с отдельным принятием Условий,
  подтверждением ознакомления с Политикой и подтверждением возраста 16+.
- При регистрации Android/Windows клиент передаёт версии юридических
  документов, а сервер сохраняет время принятия и отклоняет регистрацию без
  актуального подтверждения. Новый клиент также запрашивает подтверждение у
  существующих аккаунтов после входа, если версия устарела. Миграция пока мягкая:
  публичная сборка 4224 игнорирует дополнительные поля ответа и не блокируется.
- В настройки добавлен явно обозначенный ИИ-помощник поддержки. Он получает
  только вопрос, который пользователь сам отправил на его экране, не читает
  личные чаты, не сохраняет историю в приложении и ограничен одним запросом на
  пользователя за 10 секунд. Запросы OpenAI отправляются с `store: false`.
- Автоматизировано проверены синтаксис Node.js, анализ изменённых Dart-файлов,
  наличие юридических страниц, отсутствие прямой APK-ссылки на лендинге и
  синтаксис JavaScript окна загрузки. Запуск `flutter test` в этой среде
  остановлен из-за зависания локального Flutter launcher без диагностического
  вывода; тест устройства и публикация не выполнялись.
- Почтовые адреса `support@fenyvo.com` и `privacy@fenyvo.com` должны быть
  настроены и проверены до публикации. ИИ-поддержка реализована только в
  локальном кандидате и ещё не развёрнута на публичном сервере.

## 2026-09-30 — PRIVATE CALL EXPERIENCE / 4222

  сразу после ответа, отмены или завершения вызова.

  видеозвонки, пропущенные и отклонённые вызовы, а также длительность разговора.
- Записи истории звонков остаются локальными и не отправляются как обычные

## 2026-09-14 — LOGIN HARDENING / 4207

- Сохранённый пароль перенесён из `SharedPreferences` в системное защищённое
  хранилище через `flutter_secure_storage`.
- Добавлена безопасная автоматическая миграция: старое значение удаляется из
  обычных настроек только после успешной защищённой записи. При временной ошибке
  хранилища существующий пользователь не теряет возможность входа.
- Для Android отключено облачное резервное копирование внутренних данных
  приложения, включая защищённые ключи и сохранённые данные входа.
- Windows-клиент пересобран из тех же исходников `1.7.7+4207`; экран входа
  больше не содержит IP и порт, а сохранённый пароль использует Windows
  protected storage. Существующий фирменный ярлык переведён на новый комплект.
- Конфигурация Windows приведена в соответствие с CMake 4.3 / Visual Studio 18:
  стандартные Windows-макросы явно передаются WebRTC, а выбор динамического
  MSVC runtime задаётся до `project()`, чтобы Firebase не смешивался с `/MT`.
  Папка установки release-комплекта теперь всегда находится рядом с EXE.

  максимальная ограничена 128 символами. Старые аккаунты с коротким паролем
  продолжают входить.
- Сервер ограничивает частые попытки входа и регистрации для пары
  «адрес клиента + аккаунт» и отдельно общий поток с адреса. Лимиты и окно
  задаются `SPARTAN_AUTH_MAX_ATTEMPTS`, `SPARTAN_AUTH_IP_MAX_ATTEMPTS` и
  `SPARTAN_AUTH_WINDOW_MS`.
- Ответ при неизвестном логине и неверном пароле объединён в «Неверный логин
  или пароль»; для неизвестного аккаунта выполняется такая же дорогостоящая
  проверка, уменьшая возможность определить существование логина по времени.
- Заголовок `X-Forwarded-For` учитывается только при явном
  `SPARTAN_TRUST_PROXY=true`.
- Версия приложения обновлена до `1.7.7+4207`.

Автоматические проверки: пять Node-тестов конфигурации и защиты входа прошли;
`server.js` и `server_security.js` прошли синтаксическую проверку; изменённые
Dart-файлы отформатированы и проанализированы без ошибок; smoke-запуск сервера
на временных портах и пустой временной папке данных прошёл. Интеграционная
проверка вернула одинаковую ошибку для десяти попыток входа в неизвестный
аккаунт и заблокировала одиннадцатую. ARM64 release APK собран; версия
`1.7.7+4207` и подпись APK Signature Scheme v2 проверены. SHA-256:
`1162DC5B30AF45C0391429CCD3865784961FAE254C4822EABA715FF332503631`.
Проверка владельцем Android-сборки пройдена после установки поверх прежней
версии: запуск и повторный запуск, миграция сохранённого входа, автовход,
отсутствие IP/порта, сохранность чатов и отправка сообщений работают.
Windows release успешно собран; статически подтверждены версия EXE
`1.7.7+4207`, 38 файлов комплекта, `app.so`, WebRTC, secure-storage и Signal DLL.
Проверка владельцем Windows-сборки пройдена: фирменный ярлык запускает новый
