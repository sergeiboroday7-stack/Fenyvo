# Журнал изменений SPARTAN CHAT

## 2026-09-09 — SPARTAN TRUST explanation / 4110

- Объяснение TRUST показывается отдельным окном только при первом открытии.
- Кнопка «Понятно, больше не показывать» запоминает выбор на устройстве.
- В компактном меню оставлена кнопка информации для повторного просмотра.
- Действия доверия, блокировки и жалобы получили короткие пояснения.
- В основном меню TRUST подписан как управление доверием, блокировкой и
  жалобами.

Автоматическая проверка: Dart-анализ экрана чата и сервиса TRUST прошёл без
ошибок. Владелец подтвердил на Android и Windows 4110 первое объяснение TRUST
и компактное меню без постоянного большого описания.

## 2026-09-09 — SPARTAN TRUST server enforcement

- Сервер проверяет блокировку до отправки личного сообщения, статуса печати,
  звонка или PULSE-запроса.
- После отклонённого звонка также отсекаются его ICE-кандидаты и остальные
  пакеты сигнализации.
- Отклонённые сообщения не попадают получателю, в офлайн-очередь или push.
- Отправителю не раскрывается факт блокировки: звонки и PULSE получают только
  нейтральное состояние недоступности.
- Групповые сообщения и групповые звонки этой проверкой не затрагиваются.

Автоматическая проверка: синтаксис `server.js` проверен командой
`node --check`. Владелец подтвердил двумя реальными аккаунтами отклонение
статуса печати, личного сообщения, входящего звонка со всеми ICE-кандидатами
и PULSE-запроса.

## 2026-09-08 — SPARTAN TRUST 1.2 / 4108

- Решения доверия, блокировки и категория жалобы отправляются на сервер только
  как метаданные авторизованного аккаунта.
- Добавлены серверные события `trust_update` и `get_trust_state`.
- Сохранённое серверное состояние применяется при открытии чата на втором
  устройстве; блокировка, доверие и жалоба обновляют локальный интерфейс.
- Пустой ответ сервера не стирает локальные настройки старой версии.
- Текст переписки, аватары и локальные базы в синхронизацию не входят.

Автоматические проверки: Dart-анализ сервиса доверия и синтаксическая проверка
Node.js-сервера прошли без ошибок. Владелец подтвердил приём `trust_update`
сервером на реальном аккаунте.

Ограничение: применение полученного состояния на втором устройстве требует
отдельной проверки после сборки Android и Windows 4108.

## 2026-09-08 — Windows TRUST 1.1 toolchain fix

- Windows Release-сборка проверена на Visual Studio 18.
- Для Firebase и Flutter зафиксирован единый динамический MSVC runtime (MD).
- Добавлены совместимые настройки CMake для предупреждения coroutine в
  `permission_handler_windows`.

Автоматические проверки: Windows `flutter build windows --release` завершён
успешно. Владелец подтвердил запуск приложения на Windows.

## 2026-09-08 — SPARTAN TRUST 1.1 / 4107

- Блокировка контакта стала рабочей: новые входящие сообщения скрываются,
  уже загруженные входящие убираются из чата, а отправка из заблокированного
  чата просит сначала разблокировать контакт.
- Добавлен постоянный баннер состояния блокировки и действие разблокировки.
- Жалоба теперь требует выбора причины (мошенничество, спам, угрозы или
  другое), сохраняется локально и подтверждается заметным уведомлением.

Автоматические проверки: Dart-анализ TRUST и экрана чата без ошибок. Владелец
подтвердил на Android выбор причины жалобы, отметку «Жалоба отправлена»,
блокировку и скрытие новых сообщений.

Ограничение: блокировка звонков и PULSE-запросов будет добавлена следующим
этапом с отдельными проверками Call/Pulse-сервисов.

## 2026-09-08 — SPARTAN TRUST 1.0 / 4106

- Добавлены локальные решения доверия для контакта: доверять, заблокировать
  или пожаловаться.
- Доверенный контакт получает золотую отметку в заголовке чата; состояние
  сохраняется между запусками приложения.
- Действия доступны прямо из предупреждения SPARTAN SHIELD и меню чата.

Автоматические проверки: Dart-анализ сервиса и экрана чата без ошибок; APK
ARM64 собран. Владелец подтвердил на телефоне отметку доверия и переключение
блокировки/разблокировки.

Ограничение: в TRUST 1.0 блокировка сохраняет локальное решение; фильтрация
входящих сообщений и системных уведомлений будет добавлена отдельным этапом.

## 2026-09-08 — SPARTAN SHIELD 4105

- Добавлен локальный SPARTAN SHIELD для входящих сообщений с признаками
  запроса кодов подтверждения, денег или доступа.
- Поддержано распознавание русскоязычных фраз; предупреждение можно закрыть,
  а новое подозрительное сообщение снова вызывает проверку.
- Добавлены автоматические тесты детектора и сохранена совместимость подписи
  для обновления поверх установленной версии.

Автоматические проверки: 12 Flutter-тестов и анализ Dart без ошибок; APK
ARM64 собран, выровнен и проверен `apksigner`. Владелец подтвердил на
устройстве SHIELD, повторное предупреждение и SPARTAN PULSE со списком
запросов, счётчиками и принятием звонка.

Ограничения: предупреждение анализирует входящее текстовое сообщение на
устройстве; это не антивирус и не замена проверке контакта пользователем.

## 2026-09-07 — SPARTAN PULSE / CALL END FIX 2101

- Добавлен SPARTAN PULSE: пользователь предлагает аудио- или видеозвонок в
  течение 15 минут, часа или четырёх часов; соединение начинается после
  подтверждения готовности обоих участников.
- Добавлены серверная сигнализация PULSE, синхронизация состояния,
  уведомления, тайм-ауты приглашений и автоматические тесты протокола.
- Исправлено зависание экрана после завершения личного звонка: интерфейс
  закрывается до потенциально долгой очистки WebRTC, а этапы очистки имеют
  ограниченные тайм-ауты и гарантированный сброс состояния.
- Android-сборка обновлена до versionName `1.1.1`, versionCode `2101` и
  сохраняет прежнюю подпись для установки поверх рабочей версии.

Автоматические проверки: анализ изменённых Dart-файлов без ошибок;
`test/call_screen_test.dart` — 6 из 6 тестов успешно; APK и Windows bundle
собраны. Владелец подтвердил исправление зависания на установленной сборке.

Ограничения прежние: группового видео и TURN пока нет, чёрное удалённое видео
с телефона на Windows не объявляется исправленным; возможные лаги будут
исследоваться отдельно.

## 2026-09-04 — Актуальные исходники GROUP VOICE V1 / BLUE GOLD FIX2

Перед окончательной публикацией обнаружен уже находившийся на GitHub коммит
`69de578` от 06.09.2026. Он продолжает очищенную историю и не возвращает
известные файлы пользовательских данных или ключей, но содержит служебный
журнал Kotlin, резервный AndroidManifest, неудачные тестовые снимки и удаляет
документы сопровождения. Следующий обычный коммит сохраняет его в истории,
восстанавливает README/CHANGELOG/AGENTS и делает вершину ветки точной копией
проверенного набора исходников. Перезаписи истории для этого не требуется.

- Перенесён текущий код Flutter, Android, Windows и Node.js-сервера.
- Добавлены сине-золотой интерфейс, разделы чатов/звонков/настроек,
  поиск и фильтры чатов, сохранённые сообщения и панель смайликов.
- Включены текущие личные звонки, таймер/история и переключение громкой связи.
- Включены групповые голосовые звонки до 4 участников, приглашения,
  выход/повторный вход, взаимная занятость личных и групповых звонков.
- Добавлены автоматические тесты, экранные эталоны, фирменный звук и логотипы.
- Удалены из этой копии устаревший lib/socket_service.dart и старая памятка
  README_REACTIONS_FIX.txt: они не относятся к выбранному актуальному снимку.
- Пользовательские данные, секреты, локальные сценарии запуска, SDK, кеши,
  готовые сборки и неудачные тестовые снимки не публикуются.

Владелец подтвердил групповой звук, управление громкой связью, выход создателя
без завершения разговора остальных и повторный вход в своей Wi-Fi сети.
Подробности автоматических проверок — в docs/VERIFICATION_GROUP_VOICE_V1.md.

Ограничения: только групповой голос, до 4 участников, приложение открыто;
нет TURN, группового видео, отдельной истории группы и подсветки говорящего.
Чёрное удалённое видео на Windows и лаги не объявляются исправленными.
Это публикация исходников проверенной тестовой версии, без новой сборки APK.
