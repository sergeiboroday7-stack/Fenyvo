Установите Fenyvo

Для Android доступен подписанный APK ARM64, для Windows — полный x64-комплект в ZIP-архиве.

Скачивайте приложение только с fenyvo.com.
На Android разрешите браузеру установку APK из этого источника.
На Windows распакуйте ZIP полностью и запустите Install-Fenyvo.cmd.
